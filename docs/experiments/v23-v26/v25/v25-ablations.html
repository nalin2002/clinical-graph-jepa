Clinical Graph-JEPA v25: ablation and reproduction bundle

This package is the v24 ACI-evaluation branch plus three reproducibility additions: node-embedding replacement (Clinical-ModernBERT versus TF-IDF), discharge-node representation placement, and the three-condition ACI-Bench transfer evaluation.

Upstream base: codex/v24-aci-evaluation, commit d765566. The v25 branch is local and is not pushed.

0. Install and verify

cd clinical-graph-jepa-v25
uv sync
uv run python -c "import torch, torch_geometric, sklearn; print('dependencies OK')"
export PYTHONPATH="$PWD/src"

Python 3.10+ is required. CPU evaluation is supported. The full TF-IDF matched training arm needs PyTorch Geometric, scikit-learn, the included training graph data, and the v24 checkpoint/training environment. No API key is needed for the included evaluations. The optional v24 smoke script also checks checkpoints that are intentionally not distributed in this release.

1. Node-embedding ablation

Only the 768-dimensional discharge-note representation changes. The graph, provenance mask, model width, split seed, and downstream input width remain fixed. The Clinical-ModernBERT arm is the supplied v24/v23 data; the TF-IDF arm is word unigrams+bigrams with sublinear TF, fit on the 3,200-graph training partition only, projected with 768-dimensional TruncatedSVD, then L2-normalized.

uv run python scripts/build_tfidf_embeddings.py \
  --input ablation_artifacts/tfidf/input.jsonl \
  --output ablation_artifacts/tfidf/graphs_tfidf.jsonl \
  --metadata ablation_artifacts/tfidf/metadata.json

To obtain input.jsonl from the public dataset source before running the command:

uv run python -c "from huggingface_hub import hf_hub_download; from pathlib import Path; p=hf_hub_download('wmatbooth/fawkes-training-graph-embedded-260615','fawkes_training_graph_full_embedded_260615.jsonl',repo_type='dataset'); Path('ablation_artifacts/tfidf/input.jsonl').write_bytes(Path(p).read_bytes())"

For a matched model comparison, run the same v24/v23 training and evaluation commands with only DATA_PATH changed to the generated TF-IDF JSONL. Keep DATA_SPLIT_SEED=42, seeds 42–51, JEPA_EPOCHS=60, READOUT_EPOCHS=40, patch masking, MLP decoder, NEG_K=8, and TARGET_WEIGHT=3 unchanged. Report batch-mask AUC/AP/MRR/Hits@1/3/10 and filtered LOO MRR/Hits@1/3/10 per seed, then paired TF-IDF minus Clinical-ModernBERT differences with 95% CIs.

The bundle includes the generated TF-IDF JSONL and its metadata. The v24 GitHub branch did not contain a matched TF-IDF retraining result file, so this package does not invent final TF-IDF model metrics; it gives the exact construction and matched-run protocol.

2. Discharge-node representation ablation

The same v23 mean-note checkpoint is evaluated three ways without retraining:

ConditionImplementationMeaning
Graph-onlyZero the 768-d note channelArchitecture is retained at 774 dimensions; no real-note signal reaches any node.
Global noteGROUND_BY=allCopy the note vector to every non-patient entity.
Entity-grounded noteGROUND_BY=provCopy the vector only to entities grounded by note provenance.

These are feature-injection ablations on identical weights, topology, queries, and ranking protocol—not three separately trained models. The exact v24 JSON/HTML result is in results/v24_aci_eval/.

3. ACI-Bench evaluation

Run all three conditions on the included 207 encounter graphs and the v24 checkpoint:

uv run python scripts/evaluate_v25_aci.py \
  --checkpoint results/v24_aci_eval/fawkes_entity_note_v23_mean_sp42_s42.pt \
  --data ablation_artifacts/aci/graphs_with_clinical_modernbert_embeddings.jsonl \
  --output results/v25_aci_eval.json

The evaluator hides one forward edge at a time, removes the other true tails for the same source/relation, ranks same-type candidates, and reports MRR and Hits@K. CPU is deterministic for this leave-one-out protocol.

ConditionQueriesMRRHits@1Hits@3Hits@10
Graph-only5,0050.47460.30410.56120.8442
Global note5,0050.47160.30070.55440.8547
Entity-grounded note5,0050.48090.30490.57040.8649

These ACI graphs are out-of-distribution relative to the MIMIC graphs used to train the checkpoint. Interpret this as transfer/evaluation evidence, not clinical validation. The stored source data and checkpoint are included for exact reruns; SHA-256 values and per-relation results are recorded in results/v24_aci_eval/v24_aci_eval.json.

Bundle map

  • src/, tests/, models/, results/: v24 source, tests, checkpoint, and prior artifacts.
  • scripts/build_tfidf_embeddings.py: leakage-safe TF-IDF construction.
  • scripts/evaluate_v25_aci.py: three-condition ACI runner.
  • ablation_artifacts/aci/: 207-graph ACI input and embedding metadata.
  • ablation_artifacts/tfidf/metadata.json: TF-IDF construction metadata; the large input/output JSONL files are generated locally from the public dataset source.
