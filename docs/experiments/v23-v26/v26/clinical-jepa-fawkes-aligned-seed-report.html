Clinical-JEPA — Fawkes-aligned shared-query seed report

261001 | fixed Fawkes split seed 42 | 20 Clinical-JEPA HF jobs: note + no-note across seeds 42–51 | every model scored on the same 8,283 Fawkes-defined leave-one-out queries
Executive reading

Clinical-JEPA no-note is the best arm on the primary ranking metrics. Across 10 paired seeds, no-note beats localized-note on MRR, Hits@1 and Hits@3 for every seed. The mean no-note advantage is +0.0226 ± 0.0079 MRR, +0.0358 ± 0.0118 Hits@1, and +0.0121 ± 0.0059 Hits@3.

Localized-note is only ahead at Hits@10, and by a very small amount. The paired no-note minus note difference is −0.0011 ± 0.0008, with note ahead on 9 of 10 seeds. Both arms are already saturated near 0.99 Hits@10.

Both Clinical-JEPA variants are far above the fixed Fawkes paper checkpoint on this shared-query evaluator. Fawkes scores MRR 0.4187 on the same 8,283 query manifest; Clinical-JEPA note scores 0.8118 ± 0.0041 and no-note scores 0.8344 ± 0.0083.

Decision: for this Fawkes-aligned ranking protocol, use the Clinical-JEPA no-note checkpoint family as the default comparison arm. Treat the localized note result as a negative note-feature ablation unless a new training path is tested.

Resume behavior: each HF job first checks its output repo for a matching final checkpoint, then a matching pretrain checkpoint. Evaluation protocol

▸ Shared-query evaluator
Why this evaluator exists: the native Fawkes and Clinical-JEPA evaluators do not define identical query populations. This report uses benchmarks.shared_queries to make the comparison strict.

StepDefinition
1. Build Fawkes test splitLoad all 4,000 raw records, apply the Fawkes paper split with seed 42, and take the 400 held-out records.
2. Build one query manifestUse Fawkes filtered leave-one-out logic to define the hidden edge, relation, source, true target and candidate target IDs. This yields 8,283 queries.
3. Score FawkesRemove the hidden edge from Fawkes message passing and rank the true tail with the Fawkes checkpoint's scorer.
4. Score Clinical-JEPAAdapt the same raw held-out record into a PatientGraph, remove the same hidden edge from message passing when present, and score the exact same candidate IDs with the Clinical-JEPA edge head.
5. AggregateMRR and Hits@1/3/10 over the same denominator. Both lineages scored all 8,283 queries with zero fatal skips in the completed sweep.
Metric: leave-one-out target recovery. Higher MRR and Hits@K are better. Hits@10 is near ceiling for Clinical-JEPA and should be read as a saturation metric.

Interpretation

▸ What the comparison establishes
  • Clinical-JEPA's patch/revision/ranking pipeline is substantially stronger than the fixed Fawkes paper checkpoint under this shared-query protocol. This does not erase the lineage difference; it shows that, when forced to answer the same Fawkes-defined queries, the Clinical-JEPA edge head ranks the true target much higher.
  • The localized note feature does not help this training path. Adding a 768-d admission note vector to provenance-grounded nodes lowers MRR/Hits@1/Hits@3 relative to the same architecture without the note.
  • The no-note gain is concentrated in early rank quality. The meaningful improvements are MRR and Hits@1. Hits@10 is already saturated for both variants.
  • The note result is not a verdict on all possible note use. This note variant concatenates one global note embedding to grounded nodes. It does not train an entity-specific note retriever, span attention mechanism, or supervised note selector.
▸ Recommended next experiments
QuestionExperimentWhy
Is the note harmful because it is global and repeated?Replace the global note vector with relation/entity-local note spans, or train a note selector during fine-tuning.The present note feature may add admission-level context at nodes where target-specific evidence is not aligned.
Is no-note robust to fine-tune duration?Run a matched 90-epoch no-note arm and a 90-epoch note control, or sweep 50/70/90 for both.This sweep intentionally used 50 fine-tune epochs for both variants, while older released no-note defaults used 90.
Does the result hold outside Fawkes-defined candidates?Repeat with Clinical-JEPA's schema-candidate evaluator and with an ACI-Bench transfer set.The shared evaluator is the cleanest Fawkes comparison, but it is not the only clinically relevant ranking population.

Reproduction

▸ Commands
One-command HF sweep used for this report — 20 jobs, both variants, seeds 42–51: 
./submit-clinical-jepa-seed-variance.sh
General single HF job template: 
VARIANT=note        # or: no-note
SEED=42
SPLIT=42
OWNER=wmatbooth

.venv/bin/hf jobs uv run --detach \
  --namespace "$OWNER" \
  --flavor a10g-small \
  --timeout 8h \
  --secrets HF_TOKEN \
  --name "clinical-jepa-$VARIANT-sp$SPLIT-s$SEED" \
  -v ./src:/workspace/src \
  -v ./models:/workspace/models \
  -e VARIANT="$VARIANT" \
  -e DATA_SPLIT_SEED="$SPLIT" \
  -e SEED="$SEED" \
  -e PRETRAIN_EPOCHS=60 \
  -e FINETUNE_EPOCHS=50 \
  -e USE_TORCH=1 \
  -e USE_TF=0 \
  -e PUSH=1 \
  -e OUTPUT_REPO="$OWNER/clinical-jepa-$VARIANT-fawkes-sp$SPLIT-s$SEED" \
  scripts/clinical_jepa_hf_job.py
HF resume / force-retrain controls: 
# Default behavior: check OUTPUT_REPO for a matching final checkpoint,
# then a matching pretrain checkpoint, and skip completed stages.
-e RESUME_FROM_HF=1

# Force the job to ignore existing HF checkpoints and retrain both stages.
-e RESUME_FROM_HF=0

# Smoke-test without uploading artifacts.
-e PUSH=0 -e DATA_LIMIT=80 -e PRETRAIN_EPOCHS=1 -e FINETUNE_EPOCHS=1 -e EVAL_CAP=10
Local prerequisite for direct CLI training: the commands below expect the Fawkes-aligned train+val split file at outputs/splits/fawkes_train_plus_val.jsonl. The HF payload creates this file inside each job. Locally, this repo already has the generated split; it contains 3,600 training records from the 4,000-record dataset with split seed 42.

General local pretrain: 
VARIANT=note        # or: no-note
SEED=42
OUT="checkpoints/clinical-jepa-$VARIANT-sp42-s$SEED"
NO_NOTE_FLAG=""
if [ "$VARIANT" = "no-note" ]; then NO_NOTE_FLAG="--no-note-embeddings"; fi

PYTHONPATH=src .venv/bin/python -m clinical_jepa.train.pretrain \
  --data jsonl \
  --jsonl-path outputs/splits/fawkes_train_plus_val.jsonl \
  --out "$OUT" \
  --encoder sapbert \
  --encoder-cache .cache/clinical_jepa/encoder \
  --epochs 60 \
  --lr 8e-4 \
  --seed "$SEED" \
  --batch_size 16 \
  --device cuda \
  $NO_NOTE_FLAG
General local fine-tune from that pretrain checkpoint: 
PRETRAIN_CKPT="$OUT/clinical_jepa_note_pretrain.pt"
if [ "$VARIANT" = "no-note" ]; then PRETRAIN_CKPT="$OUT/clinical_jepa_no_note_pretrain.pt"; fi

PYTHONPATH=src .venv/bin/python -m clinical_jepa.train.finetune \
  --data jsonl \
  --jsonl-path outputs/splits/fawkes_train_plus_val.jsonl \
  --checkpoint "$PRETRAIN_CKPT" \
  --out "$OUT" \
  --encoder-cache .cache/clinical_jepa/encoder \
  --epochs 50 \
  --lr 8e-4 \
  --seed "$SEED" \
  --batch_size 16 \
  --device cuda \
  --llm-confidence-negatives \
  --clinical-artifact-filters \
  --llm-negative-weight 0.6
Run the shared-query evaluator on the local checkpoint: 
FINAL_CKPT="$OUT/clinical_jepa_note.pt"
if [ "$VARIANT" = "no-note" ]; then FINAL_CKPT="$OUT/clinical_jepa_no_note.pt"; fi

PYTHONPATH=src .venv/bin/python -m benchmarks.shared_queries \
  --data data/fawkes-training-graph-embedded-260615/fawkes_training_graph_full_embedded_260615.jsonl \
  --fawkes-checkpoint models/fawkes-entity-note/fawkes_trainer_jepa_entity_note_v16_260615.pt \
  --checkpoint "$FINAL_CKPT" \
  --encoder-cache .cache/clinical_jepa/encoder \
  --device cuda \
  --cap 40000 \
  --output "outputs/shared_queries_${VARIANT}_sp42_s${SEED}.json"
Aggregate uploaded HF eval files into the tables above: 
CLINICAL_JEPA_HF_USER=wmatbooth PYTHONPATH=src .venv/bin/python print_clinical_jepa_seed_table.py

Known limits

▸ What not to overclaim
  • Fawkes has one fixed checkpoint in this table. The Clinical-JEPA rows are mean ± std over 10 seeds; the Fawkes row is not a Fawkes seed variance estimate.
  • The evaluator is Fawkes-aligned. It is deliberately fair for cross-lineage comparison, but it inherits Fawkes' filtered candidate manifest and relation mix.
  • The note and no-note arms were trained with the same 50 fine-tune epochs here. Do not merge these results with older Clinical-JEPA defaults unless the training schedule is explicitly matched.
  • Hits@10 is near ceiling. The small note advantage there is statistically consistent but operationally much less important than the larger no-note gains at MRR/Hits@1.
