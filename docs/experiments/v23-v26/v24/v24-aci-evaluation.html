Clinical Graph-JEPA v24 — ACI Bench Evaluation

Evaluation-only reanalysis. v23 mean-note checkpoint used as the model artifact; no JEPA retraining was performed. v23 mean is the exact v22 global-mean pipeline, evaluated here under the new v24 ACI protocol.

Protocol

Each trusted edge is hidden once. The model ranks the true tail against same-type candidates in the same encounter, filtering other true tails for the same (source, relation). Higher MRR and Hits@K are better.
  • Model: v23 mean-note, seed 42, patch masking + MLP readout.
  • Data: 207 ACI-Bench encounter graphs with stored 768-d Clinical ModernBERT embeddings.
  • Conditions: graph-only (note vector zeroed), global note (copied to every non-patient entity), entity-grounded note (copied only to provenance-grounded entities).
  • All conditions use identical graph topology, checkpoint, ranking protocol, and CPU execution.

  • Graph-only means the checkpoint's 768-dimensional note channel is retained as zeros so the 774-dimensional checkpoint architecture remains unchanged; it is not a separately trained no-note checkpoint.
  • Global note and entity-grounded note are feature-injection ablations on the same v23 weights, not retrained models.
  • ACI encounter graphs are out-of-distribution relative to the MIMIC admission graphs used for training. Results should be interpreted as transfer/evaluation evidence, not as a new clinical benchmark.
  • Queries omitted by the evaluator had fewer than two candidates or were otherwise not rankable; the query count is the exact evaluated denominator for each condition.
